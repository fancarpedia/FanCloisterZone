What this build does

The offline web build: everything it needs is already in the page.

No downloads, ever

The bundled simplified artwork ships with the site. No Mega, no GitHub, no CDN — the only network traffic is the game connection itself.

The real game engine

The full TypeScript JCloisterZone engine runs in a Web Worker, right in your browser. Same rules, same scoring as the desktop app.

Online play & lobby

Connect to the Fan server for public and private games, the lobby player list, and global chat.

Settings that stick

Preferences, nickname and theme are stored in your browser, so they survive a reload just like the desktop config file.

Local games: not yet

Hot-seat and solo games against the AI still need the embedded server, which has no browser equivalent yet. Use the desktop app for those.

Simplified artwork only

The classic tile artwork and optional add-ons are a desktop feature in this build — nothing is downloaded at runtime.
